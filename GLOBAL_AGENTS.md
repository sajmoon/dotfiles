# Agent Instructions

- Prefer high-quality, maintainable software over quick wins; quality matters more than time to completion.
- Never add LLM/AI attribution to commits (no `Co-Authored-By` or `Generated with …` trailers).
- When rebasing a feature branch onto main after a lot of back-and-forth, squash the noisy work-in-progress commits into coherent logical commits.
- Be extremely concise. Sacrifice grammar for the sake of concision. Use ASD-STE100 Simplified Technical English.
